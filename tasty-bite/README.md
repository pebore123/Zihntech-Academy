# 🍽️ Tasty-Bite Restaurant Landing Page

## 📖 Overview

Tasty-Bite is a modern restaurant landing page built with **HTML5** and **CSS3**. The project showcases a clean and visually appealing user interface for a restaurant business. It was developed to practice semantic HTML, CSS styling, Flexbox layout, spacing, typography, and responsive web design principles.

The website provides visitors with essential restaurant information, including menu highlights, gallery, customer reviews, opening hours, contact details, and social media links through a professional and user-friendly layout.

---

## ✨ Features

- Responsive navigation bar
- Hero section with call-to-action button
- About Us section
- Menu section
- Food Gallery
- Customer Reviews section
- Professional Footer containing:
  - Restaurant logo
  - Social media icons
  - Useful links
  - Opening hours
  - Contact information
- Clean and organized layout
- Modern typography
- Flexbox-based page structure
